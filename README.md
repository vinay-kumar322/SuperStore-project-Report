# SuperStore Sales Report Dashboard

## Project Overview
This project is an interactive Power BI dashboard developed using the SuperStore dataset. The dashboard provides insights into sales performance, profitability, customer behavior, regional performance, and year-over-year growth. It helps business stakeholders monitor key metrics and make data-driven decisions.

## Business Objective
The objective of this dashboard is to analyze sales trends, identify profitable categories and customers, evaluate regional performance, and track yearly business growth.

## Tools Used
- Power BI Desktop
- Power Query Editor
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV Dataset

## Data Cleaning & Transformation
The following data preparation steps were performed using Power Query:

- Removed duplicate records
- Handled missing and null values
- Corrected data types
- Renamed columns for better readability
- Created calculated columns where required
- Standardized category and segment values
- Validated sales and profit records

## KPI Questions Answered

1. What is the total sales generated?
2. What is the total profit earned?
3. What is the total quantity sold?
4. What is the overall profit percentage?
5. What is the Year-over-Year (YOY) growth percentage?
6. Which category generates the highest profit?
7. Which region contributes the most profit?
8. Which customer generates the highest profit?
9. Which sub-category contributes the highest profit?
10. How do monthly sales compare with the previous year?
